## ✍️ Tips for Success

- Don’t just memorize — understand the *why* behind each step.
- Use visual intuition where possible (e.g., slope fields for differential equations).
- Practice solving problems without a calculator first — it strengthens your fundamentals.

> [!NOTE]
> Calculators wouldn't be allowed in the final exams anyways, so it would be better if you guys got yourself accustomed to alot of mental math. Look on the bright side tho, it does improve cognitive thinking (hopefully lol).
